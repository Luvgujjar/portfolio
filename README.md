# 💼 Personal Portfolio

A modern, responsive personal portfolio website built with **Next.js, React, TypeScript, and Tailwind CSS**.

The portfolio showcases my development experience, projects, technical skills, education, achievements, and ways to get in touch.

🌐 **Live Website:**
https://portfolio-seven-topaz-xlpyqzdyyz.vercel.app/

---

## ✨ Features

* 🎨 Modern and responsive UI
* 📱 Mobile-first design
* ⚡ Built with Next.js App Router
* 🧩 Reusable React components
* 🎯 Dedicated sections for experience, projects, skills, education and achievements
* 🔗 Project and social links
* 📬 Contact section
* 🚀 Optimized for production deployment
* 🌓 Clean and minimal developer-focused design

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Luvgujjar/portfolio.git
```

### 2. Navigate to the project

```bash
cd portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

The development server will automatically reload when you make changes.

The application follows a component-based architecture using React and Next.js.

The project is structured to keep the application maintainable by separating:

* Page-level application logic
* Reusable UI components
* Utility/helper functionality
* Static assets
